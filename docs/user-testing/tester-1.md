## 3. Tasks Given

Each task is read aloud to the tester. They attempt it unaided; the facilitator
only steps in if the tester is fully stuck (mark as **Fail** if assistance was needed).

| # | Task | Success criteria |
|---|------|------------------|
| 1 | From the Home screen, find your next/upcoming class and start navigating to it. | Taps **Navigate** on the Upcoming Class card → lands on Map with DK1 as destination. |
| 2 | From Home, use a quick category to find the **Cafe**. | Taps the **CAFE** category chip and reaches the cafe location/result. |
| 3 | Search for **"AI Lab"** and open it on the map. | Uses Search tab, types query, taps the AI Lab 01 result → Map opens with it pre-selected. |
| 4 | Find lecturer **Dr Suraya Yaacob** and navigate to her room. | Locates staff via Search or Directory, taps **Navigate** → Map shows room A-07-08. |
| 5 | On the Map screen, set **AI Lab 01** as the destination and start the route. | Destination shows "TO AI LAB 01", taps **Find Route**. |
| 6 | While on the Map, switch to a different **floor** using the floor selector. | Taps a floor button (3/2/1) and notices the change. |
| 7 | Open the **Directory**, filter to **Lecturers**, and navigate to any lecturer's office. | Applies Lecturers filter, taps **Navigate** on a card → Map opens. |
| 8 | Return to the **Home** screen using the bottom navigation bar. | Taps the Home tab; Home dashboard is shown. |
